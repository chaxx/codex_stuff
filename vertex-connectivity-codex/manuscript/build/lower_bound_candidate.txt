          We give a self-contained proof of the supplied draft’s deterministic Ω( n) lower bound
      for exact Boolean connectivity in the simultaneous vertex-neighborhood model, with explicit
      alphabet and bit constants. We also establish limits on several proposed collision arguments:
      local linear maps with r + ⌈log2 n⌉ bits exclude every nonzero adjacency difference of binary
                                                                                                  rank
      at most r; local XOR-linear cut-space recognizers have concatenated rank at least m      2 − 1; a
      four-vertex example defeats a particular anchored collision template; and public r-sheet√lifts have
      a direct reconstruction protocol. These results do not improve the unrestricted Ω( n) lower
      bound. This is an independent addendum, with no claim of novelty or author acceptance.


1    Definitions and scope
An input is a simple undirected graph G on the public labeled vertex set [n]. Player v knows exactly
its own neighborhood NG (v) and sends one deterministic message to a referee. All messages are
simultaneous. Encoders may be vertex-specific and nonlinear, and the referee has no computational
restriction. The required output is the single bit indicating whether G is connected, with correctness
on every input. No shared knowledge of other vertices’ neighborhoods is available.
    The communication cost B is the worst-case maximum bits sent by one vertex, not the total
number of bits. We distinguish a message alphabet of cardinality at most 2b , fixed-length binary
messages, and arbitrary binary strings of maximum length B. All logarithms are base two unless
written ln. Only ordinary connectivity, or k = 1, is treated here.
                                                        (n)
    For algebraic statements, edge indicators lie in F2 2 , with the fixed ambient edge set [n]

adjacency difference D is a symmetric zero-diagonal matrix over F2 ; Dv denotes its incident row
with the diagonal coordinate omitted. The ranks of these adjacency matrices and the ranks of
concatenated message maps are different quantities.

   The maps in this theorem are deterministic after being fixed by an existence argument. The
theorem supplies neither a connectivity-deciding referee nor an efficient uniform construction of the
maps. A chosen dense map can be evaluated in O(nb) binary operations per vertex.

an assumed correct connectivity protocol, exclude high-rank collisions, or give an unrestricted
connectivity upper bound. If b > n − 1, full-row transmission already provides a simpler separator.

5    The cost of describing public graph lifts
Proposition 5.1 (Public-base reconstruction). Fix a public simple base graph H on m labeled
vertices and an integer r ≥ 2. The input has public labels (v, a) ∈ V (H) × [r] and is promised to be
an r-sheet lift: every base edge is replaced by a perfect matching between its two fibers, and there
are no other edges. There is an exact deterministic simultaneous protocol reconstructing the entire
input, and hence deciding connectivity, with at most

                                             ∆(H) ⌈log2 r⌉

bits per lifted vertex and polynomial decoding time.

Proof. Order the neighbors of each base vertex using the public labels. Vertex (v, a) has exactly
one neighbor in each fiber u with u ∈ NH (v). In that order, it sends the sheet index of each such
neighbor, using ⌈log2 r⌉ bits per index. Its message is computed from its own neighborhood. The
referee knows the order and the base labels, so it reconstructs all edges from these indices. Ordinary
graph search decides connectivity. The encoding and decoding are polynomial in the explicit input
and output sizes.

   For H = Km and n = mr, the budget is (m − 1) ⌈log2 r⌉ = O((n/r) log r). Along a growing
sequence of such families, for any fixed C ≥ 0, the condition
                                             r
                                                 = ω(logC n)
                                           log r

makes this budget o(n/ logC n) and therefore rules out an Ω(n/ logC n) lower bound on that promise
family. The public base and public fiber labels are essential assumptions. The proposition supplies
no such protocol when these data are hidden, and no upper bound for arbitrary graphs.
