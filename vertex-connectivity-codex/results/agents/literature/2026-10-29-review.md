# Literature check for the deterministic connectivity harness

Date: 2026-10-29. Role: `literature`. This report checks source statements and model applicability; it is not an independent proof audit of the cited papers. No other specialist's current analysis was used.

## Finding

The strongest **external unrestricted deterministic ordinary-connectivity lower bound located and source-checked in this bounded search** is Ω(n^(1/3)) worst-case bits per vertex, due to Robinson and Tan (September 2026). The supplied draft's Ω(√n) claim is a separate project result requiring the harness's mathematical audit. I found no external result establishing Ω(n/polylog n) in the requested model, but this search does not certify absence or novelty.

The target model is n labeled vertices, each receiving only its neighborhood, each sending one simultaneous message, and an unrestricted referee deciding connectivity exactly. A theorem for linear encoders, forest recovery, total stream space, multiple communication rounds, or two parties with edge-set inputs does not automatically prove the target lower bound.

## Source-checked benchmarks and boundaries

### Robinson–Tan, tiny-error graph sketching, September 2026

Peter Robinson and Ming Ming Tan, *Polynomial Lower Bounds for Distributed Graph Sketching with Tiny Error: Connectivity and Spanning Tree Construction*, [arXiv:2609.05795v1](https://arxiv.org/abs/2609.05795v1), submitted 5 September 2026. [Full text](https://arxiv.org/html/2609.05795v1), Sections 1.1–1.2, **Theorem 1 and Corollary 1**.

Section 1.1 says: “Every node knows its neighbors’ IDs as well as n”. It specifies IDs in [n], one B-bit message to a referee with no prior graph information, and shared randomness for randomized protocols. Theorem 1 gives Ω(min{n, log₂(1/δ)}^(1/3)) worst-case message length for δ ≤ 1/n^(log⁸ n), for connectivity decision or spanning-tree construction. Corollary 1 explicitly gives Ω(n^(1/3)) for deterministic protocols. This matches the target communication convention and covers arbitrary message functions; no linearity restriction appears in the model. The source distinguishes forest recovery on all graphs from tree recovery promised a connected graph.

### Robinson–Tan, k-edge connectivity, PODS 2026

Peter Robinson and Ming Ming Tan, *Deterministic Lower Bounds for k-Edge Connectivity in the Distributed Sketching Model*, [arXiv:2507.11257v2](https://arxiv.org/abs/2507.11257v2), initially submitted 15 July 2025, revised 9 February 2026, accepted at PODS 2026. [Full text](https://arxiv.org/html/2507.11257v2), **Theorem 1**: deterministic worst-case messages require Ω(k) for superconstant k ≤ γ√n, for an absolute suitable γ>0. This is **edge connectivity**, not vertex connectivity. Substituting k≈√n changes the problem; it does not yield Ω(√n) for ordinary connectivity at k=1. The theorem cannot supply the draft's asserted k=1 improvement.

### Yu, randomized Boolean connectivity, SODA 2021

Huacheng Yu, *Tight Distributed Sketching Lower Bound for Connectivity*, [primary arXiv record](https://arxiv.org/abs/2007.12323), first submitted 24 July 2020; [SODA 2021 publication](https://epubs.siam.org/doi/10.1137/1.9781611976465.111), published 7 January 2021, pp. 1856–1873. The primary abstract specifies the same vertex-neighborhood simultaneous-message model and proves Ω(log³ n) **expected average** message length for error at most 1/4. Thus it implies a worst-case maximum-message lower bound of that order. It is already a **decision** lower bound, unlike a result proved only for spanning forests. No theorem number is asserted here because this check used the primary abstract/publication statement.

### Zhang, two-party connectivity, October 2026

Zhijun Zhang, *Settling Nondeterministic Communication Complexity of Graph Connectivity*, [arXiv:2610.32346v1](https://arxiv.org/abs/2610.32346v1), submitted 23 October 2026. [PDF](https://arxiv.org/pdf/2610.32346), Introduction and **Theorem 1.1**, identified there as an informal version of Theorem 4.1. The model gives Alice and Bob “disjoint edge sets” whose union is the graph. The reported nondeterministic complexity is Θ(N log N), measuring total two-party communication on an N-vertex graph. This is a different input allocation: an edge's endpoints both know it in the target model, whereas one two-party holder need not know a vertex's full neighborhood.

**Reduction requirement (our model comparison):** a use of a two-party result must specify which party can compute every simulated vertex message and count all simulated messages. Neither dividing Ω(N log N) by a constant nor by N without such a simulation is valid. The two-party forest protocol also explains why this theorem alone is not a quadratic-total-communication theorem for the target problem.

### Roughgarden–Vassilvitskii–Wang, polynomial degree

Tim Roughgarden, Sergei Vassilvitskii, Joshua R. Wang, *Shuffles and Circuits (On Lower Bounds for Modern Parallel Computation)*, [author-hosted manuscript](https://timroughgarden.org/papers/mr.pdf), dated 16 August 2017; preliminary SPAA 2016 version. **Theorem 5.3** establishes real multilinear degree binom(n,2) for undirected connectivity. Its proof computes parity difference (−1)^(n−1)(n−1)!.

**Characteristic boundary (our deduction):** that top-degree integer coefficient becomes zero modulo a prime p≤n−1. The theorem therefore is not, by itself, a source for full degree over every finite field. The prior note's characteristic-dependent degree formula must be proved separately. The theorem also concerns polynomial degree and a massively parallel computation model, not unrestricted per-vertex deterministic message complexity.

### AGM, randomized sketches and fixed edge coordinates

Kook Jin Ahn, Sudipto Guha, Andrew McGregor, *Analyzing Graph Structure via Linear Measurements*, SODA 2012. [Author-hosted paper](https://people.cs.umass.edu/~mcgregor/papers/12-dynamic.pdf), **Definition 2, Lemma 3.1, Theorem 3.1**. The signed incidence representation has n rows and binom(n,2) columns; sums of rows retain binom(n,2) coordinates and cancel internal edges. Theorem 3.1 gives a randomized single-pass O(n log³ n)-space spanning-forest algorithm. This supports the workspace's fixed-ambient-edge convention during contraction. It is an upper-bound construction using randomized linear sketches, not a lower bound for arbitrary deterministic encoders. The title-matching Stanford course PDF found during search was a student review and was excluded as a primary source.
