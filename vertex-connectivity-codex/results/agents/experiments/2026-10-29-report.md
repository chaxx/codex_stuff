# Finite experiments for deterministic connectivity, 2026-10-29

## Scope and outcome

These checks concern the vertex-local simultaneous model from `context/definitions.md`. Each base player sees only its incident edge-label bits. The new exhaustive search allows arbitrary nonlinear, vertex-specific encoders and an arbitrary referee, but **one bit means a two-symbol alphabet / fixed one-bit message**. It does not include a three-symbol alphabet encoded as the empty string, `0`, and `1` under a variable-length convention.

No asymptotic improvement to the unrestricted connectivity lower bound is obtained. The most useful new finite result is a solver-independent exhaustive exclusion of one-bit cut recognition on `K_4`. A separate explicit example shows why the zero-root symmetric-collision target is stronger than the collision statement actually needed by the lift reduction.

## 1. Exact finite cut-recognition search

For a fixed `m`, enumerate all `2^binom(m,2)` edge labelings. The cut labelings are all `delta s`, with one coordinate of `s` fixed to zero. Correctness is exactly the requirement that every cut/noncut pair differs in at least one player's message. This is sufficient even for an unrestricted referee: assign cut to transcripts realized by cuts and noncut to all other transcripts.

A Boolean local function on `2^(m-1)` star inputs can be normalized to output zero on the all-zero input by complementing its message and adjusting the referee. Thus there are `2^(2^(m-1)-1)` local maps to consider per vertex, with no loss of generality.

The search represents cut/noncut separation constraints by bitsets. After assigning functions to the first `d` vertices, it prunes only if an unseparated pair has identical local inputs at every remaining vertex. Such a pair cannot be separated by any completion. This is a sound exact pruning rule and does not assume linearity or mergeability.

| Base size | Local maps per player after normalization | Normalized tuples in search universe | Cut/noncut constraints | Result |
|---|---:|---:|---:|---|
| `m=3` | 8 | 512 | 16 | Feasible; returned tables `[0,6,10]` |
| `m=4` | 128 | 268,435,456 | 448 | No feasible protocol |

Table integer bit `a` is the output on local star input `a`; incident edges are ordered by lexicographic global edge order. The `m=3` positive witness was rechecked directly against every input without using search bitsets.

For `m=4`, nodes visited at depths `0,1,2,3,4` were respectively `[1,128,16384,401408,81920]`, a total of 499,841. The Python search took 0.275 seconds; C++ took about 0.0017 seconds. Every one of the 128^4 possible normalized tuples is either ruled out by a sound prefix constraint or explicitly tested. There is no floating-point reasoning in this result.

This proves a **finite computational statement about this precisely bounded universe**, not an asymptotic theorem. With the trivial two-bit protocol that assigns each of the six edges to an endpoint of a balanced orientation and reports all labels, the fixed-length maximum cost for cut recognition on `K_4` is exactly two bits. This does not by itself improve the graph-connectivity lower bound.

## 2. Explicit distinction between anchored and unrestricted collisions

Use `m=4`, root `0`, and candidates `s=(0,s1,s2,s3)`. Define

- `h0(s)=s1`,
- `h1(s)=s2`,
- `h2(s)=s3`,
- `h3(s)=s1`.

For a symmetric zero-diagonal binary matrix `D` with zero root row, the only possible nonzero edges are `12,23,13`. The messages at vertices `1,2,3` respectively see changes `D12,D23,D31`. If all three messages are unchanged under `s -> s+D_v`, all three edges are zero. Therefore **no nonzero anchored perturbation can collide, for any anchor `s`**. This is a short mathematical proof independent of the numerical solver; all 8 anchors and 7 nonzero differences were also checked.

Nevertheless these same functions fail to recognize cuts. Let `x=0` be the zero cut, and let `x'` have labels one exactly on edges `02` and `23`. For candidates

`P_v(x)_i = x_vi + x_v0`,

both inputs have transcript `(0,0,0,0)`, while `x'` is not a cut (triangle `012` has odd parity). The colliding input has a nonzero root row, so it lies outside the anchored search universe.

This is **not a counterexample to the asymptotic target for `b=o(m)`**. It refutes only an overstrong small-size assertion that every one-bit family at `m=4` has an anchored collision, and illustrates the extra restriction imposed by forcing the root star to be fixed.

More generally, orient the complete graph on the `m-1` nonroot vertices with maximum outdegree `ceil((m-2)/2)`. Let each nonroot player report the candidate coordinates at its outgoing neighbors. Then every nonzero zero-root `D` changes at least one reported coordinate. Thus a universal anchored-collision theorem cannot hold all the way through `b=ceil((m-2)/2)`. This bounds a possible constant; it leaves the sublinear target open.

## 3. Anchored one-bit MILP at `m=4,5`

Variables are the arbitrary Boolean truth tables of the nonroot players and auxiliary exact XOR differences. Each of the four standard linear inequalities for `y = a XOR b` is imposed, and every pair `(anchor s, nonzero D)` must have a changed message. Since `D_vv=0`, each player's own candidate coordinate is unchanged; complementing the output separately on its two own-coordinate slices preserves all constraints. The model fixes these two harmless symmetries.

| `m` | Anchors | Nonzero zero-root differences | Binary variables | Constraints | Solver result |
|---|---:|---:|---:|---:|---|
| 4 | 8 | 7 | 60 | 200 | Feasible; returned tables rechecked exactly |
| 5 | 16 | 63 | 288 | 1,904 | HiGHS reports infeasible in 10.25 s |

The `m=5` result is **solver evidence only**. No independently checkable infeasibility certificate was produced. It is not a proof for all `m`, and the report does not claim otherwise. The `m=4` feasibility result is stronger epistemically because the returned truth tables are independently checkable, and the simpler projection example above has an elementary proof.

## 4. Two-lift and rank checks

An independent implementation compares union-find component counts in the two-lift against a root path-potential test of whether the labels are a cut. It exhausts every labeling for `2<=m<=6`, totalling 33,866 cases. Each cut produces exactly two components; each noncut produces exactly one. This supports the two-lift lemma but does not replace its general proof.

The same enumeration computes binary ranks of every symmetric zero-diagonal matrix in these sizes. All ranks are even. Counts by rank are:

| `m` | rank 0 | rank 2 | rank 4 | rank 6 |
|---|---:|---:|---:|---:|
| 2 | 1 | 1 | 0 | 0 |
| 3 | 1 | 7 | 0 | 0 |
| 4 | 1 | 35 | 28 | 0 |
| 5 | 1 | 155 | 868 | 0 |
| 6 | 1 | 651 | 18,228 | 13,888 |

For every tested `m,r`, the number of these matrices of rank at most `r` is at most `2^(r*m)`. This is finite sanity evidence for the sharper counting estimate suggested by the algebraic specialist; I did not inspect that specialist's proof. It does not establish the general estimate or the sharpened sketch barrier.

## Limitations and next experiments

- Exact finite enumeration establishes only the fixed small instance and alphabet size stated above.
- MILP infeasibility needs an auditable certificate or a separate mathematical proof before it becomes a proof-grade result.
- The zero-root restriction must remain explicit when interpreting a witness or absence of a witness.
- A useful next finite target would be a formal certificate for the `m=5,b=1` anchored case, or a structural classification of its local truth tables. Merely increasing solver time is not a substitute for understanding the obstruction.
- Nothing here promotes the unrestricted `Omega(sqrt(n))` baseline to a stronger asymptotic lower bound, and no literature novelty claim is made.
