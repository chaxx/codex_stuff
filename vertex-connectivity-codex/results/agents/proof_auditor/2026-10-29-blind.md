## D01: unrestricted deterministic connectivity baseline

**Statement received.** For every integer `n >= 2`, every exact protocol with each message alphabet of cardinality at most `2^b`, for integer `b >= 1`, satisfies

`b > n / (768(ceil(sqrt(n)) + 1)) > sqrt(n)/2304`.

For fixed-length maximum `B` bits this gives `B > sqrt(n)/2304`; for variable-length binary strings of maximum length `B`, it gives `B > sqrt(n)/4608`.

**Blind verdict: UNRESOLVED.** No counterexample was found, but the central alphabet lower bound has not been independently proved. It must not receive VERIFIED status on the basis of this blind report. There is no proposed proof yet to identify a first flawed inference.

**Independently checked consequences and edge cases.**

1. Since `n >= 2`, the empty graph and a connected graph exist. All messages cannot be constant. Thus any feasible maximum bit budget is at least one, even when zero-length strings are permitted.
2. `ceil(sqrt(n)) + 1 <= sqrt(n) + 2 < 3 sqrt(n)` for `n >= 2`, so the stated square-root consequence follows from the alphabet bound, with a strict inequality.
3. Fixed-length `B`-bit messages have alphabet size at most `2^B`; shorter fixed-alphabet encodings can be padded. Since `B >= 1`, the alphabet theorem applies directly.
4. The set of binary strings of length at most `B` has size `2^(B+1)-1 < 2^(B+1)`. Applying the alphabet theorem with `b=B+1`, then using `B+1 <= 2B` for `B >= 1`, proves the variable-length consequence. This conversion is conditional only on the central alphabet theorem, and introduces no asymptotic ambiguity.
5. At `n=2`, a one-bit message from an endpoint decides connectivity. The claimed threshold is far below one. More generally, whenever the displayed threshold is below one, it follows just from `b >= 1`; these cases cannot test the substantive argument.
6. The constants are weak enough that exhaustive small-graph computation could not establish the substantive asymptotic claim. No such computation was substituted for proof.

**Independent attack attempted.** Restricting to two reservoir cliques and peripheral vertices whose neighborhoods vary yields many local collisions, but a collision among transcripts of disconnected graphs does not itself produce a connected graph with the same transcript. In particular, switching a peripheral vertex's attachment entirely from one component to the other preserves disconnection. Any proof using that family needs an additional, justified hybrid or communication reduction. This observation is a warning about an attempted blind proof path, not an allegation about the withheld proof.

## A: cut-space recognition by vertex-local XOR-linear maps

**Statement received.** For `m >= 3`, let `C_m` be the binary cut space on `K_m`, namely all edge vectors `x_uv=s_u+s_v`. If vertex-local XOR-linear maps of the incident edge labels, concatenated into a linear map `L`, allow an arbitrary referee to recognize `C_m` exactly, then `rank L >= binom(m,2)-1`.

**Blind verdict: VERIFIED (complete independent proof).**

Let `K=ker L`. Because zero is a cut vector and every vector in `K` has the same transcript as zero, correctness implies `K subseteq C_m`.

Suppose for contradiction that `dim K >= 2`. Choose independent cuts `delta s, delta t` in `K`, where `(delta s)_uv=s_u+s_v`, and similarly for `t`. Define

`x_uv = s_v t_u + t_v s_u` over `F_2`.

This is symmetric with zero diagonal. At any vertex `v`, its incident row is

`x_v = s_v (delta t)_v + t_v (delta s)_v`,

since the two copies of `s_v t_v` cancel. Vertex locality and linearity therefore give `L_v(x_v)=0`. Hence `x` belongs to `K`.

Let `z_v=(s_v,t_v)` in `F_2^2`. These labels affinely span `F_2^2`: otherwise there would be a nonzero pair `(a,b)` and a constant `c` such that `a s_v+b t_v=c` for every `v`, implying `a delta s+b delta t=0`, contrary to independence. Thus there exist vertices `p,q,r` for which `z_q+z_p` and `z_r+z_p` are linearly independent. On this triangle,

`x_pq+x_qr+x_rp = det(z_q+z_p, z_r+z_p) = 1`.

Every cut vector has triangle XOR zero. Consequently `x` is not a cut, contradicting `x in K subseteq C_m`. Thus `dim K <= 1`, and rank-nullity proves the claimed bound.

This proof uses neither a common local map nor any linearity of the referee. It is restricted to linear encoders; the first implication concerning `K` alone does not extend the whole proof to arbitrary nonlinear encoders. The conclusion is a bound on total concatenated rank, not directly on maximum per-vertex communication.

## B: bounded-rank differences can be separated by short local XOR maps

**Strengthened statement received.** For all integers `n >= 2` and `r >= 0`, there exist local binary linear maps with `b=r+ceil(log_2 n)+2` output bits per vertex such that the global kernel contains no nonzero symmetric zero-diagonal binary adjacency difference of rank at most `r`. These maps are not asserted to decide connectivity.

**Blind verdict: VERIFIED (complete independent existence proof).**

Independently sample all coefficients of each `b x (n-1)` local matrix uniformly in `F_2`. For a fixed nonzero adjacency difference `D`, let `T` be its active vertex set, consisting of vertices with a nonzero incident row, and write `t=|T|`. Independence between vertex maps and uniformity of each nonzero row's image give

`Pr[L(D)=0] = 2^(-bt)`.

We need a count respecting the active set, not merely a count of all matrices on `n` vertices.

**Counting lemma.** On a fixed set of `t` vertices, there are at most `2^(rt)` symmetric zero-diagonal binary matrices of rank at most `r`.

**Proof.** Such matrices are alternating bilinear forms over `F_2`. Their ranks are even, and the elementary symplectic normal form expresses every rank-`2k` form as `U J_(2k) U^T`, where `J_(2k)` is a direct sum of `k` matrices `[[0,1],[1,0]]`. Put `r'=2 floor(r/2)`. Padding `U` with zero columns expresses every rank-at-most-`r` form as `U J_(r') U^T` for a `t x r'` matrix `U`. There are at most `2^(r't) <= 2^(rt)` choices. The representation may be many-to-one, which is harmless for the upper bound. For `r'=0` it represents only zero, as required. The symplectic normal form follows by choosing a pair with nonzero pairing, splitting off their nondegenerate two-dimensional span, and iterating on its orthogonal complement.

Union-bound over the actual active vertex sets. Including extra zero or smaller-support matrices in the counting bound is harmless, because only actual active-support matrices are assigned the probability `2^(-bt)`. We obtain

`Pr[there exists a forbidden nonzero D in ker L]`

`<= sum_(t=1)^n binom(n,t) 2^(rt) 2^(-bt)`

`<= sum_(t=1)^n [n 2^(r-b)]^t`

`<= sum_(t=1)^infinity 4^(-t) = 1/3 < 1`.

Thus some fixed deterministic collection of maps has the desired property. This is a probabilistic existence proof of deterministic maps, not a randomized-protocol claim. Rank zero and rank one contain no nonzero alternating matrices; large `r` and output budgets exceeding the input dimension cause no problem. It does not certify any claim about separating all connected graphs from all disconnected graphs.

## Four-vertex anchored-shift counterexample

**Statement received.** In the gauge space `S={s in F_2^4:s_0=0}`, set `h_0(s)=s_1`, `h_1(s)=s_2`, `h_2(s)=s_3`, and `h_3(s)=s_1`. There is no `s` and nonzero symmetric zero-diagonal matrix `D` with `D_0=0` and `h_v(s+D_v)=h_v(s)` for every `v`. Nevertheless the local protocol `h_v(P_v(x))`, where `P_v(x)_i=x_vi+x_v0`, does not recognize cut space.

**Blind verdict: VERIFIED (direct calculation).** Since the `h_v` are linear, the value of `s` is irrelevant. The anchor condition forces `D_01=D_02=D_03=0`. The preservation conditions at vertices `1,2,3` force respectively `D_12=0`, `D_23=0`, and `D_31=0`. These are all six possible edges, so `D=0`.

For an arbitrary edge labeling `x`, the four actual messages are

`(x_01, x_12+x_10, x_23+x_20, x_31+x_30)`.

The labeling with `x_02=x_23=1` and all other edges zero therefore has zero transcript, exactly as the zero labeling does. It is not a cut, since triangle `(0,1,2)` has XOR one. Thus failure of that particular anchored collision template is not sufficient to establish correctness of the local protocol. The claim is finite-scope and does not refute an asymptotic nonlinear lower bound.

## Public lifts

**Statement received.** For a public labeled base graph `H` on `m` vertices and integer `r >= 2`, a standard `r`-sheet lift with public labels `(v,a)` can be reconstructed exactly using at most `Delta(H) ceil(log_2 r)` bits per lifted vertex.

**Blind verdict: VERIFIED (direct protocol).** Order the public neighbors `u` of each base vertex `v`. At lifted vertex `(v,a)`, encode the sheet index of its unique neighbor in the `u`-fiber for each such `u`, using `ceil(log_2 r)` bits each. The promise of a perfect matching supplies exactly one neighbor per base neighbor. The referee knows the order and all base labels, and reconstructs every lifted edge from these reports. The maximum message length is the claimed bound, and decoding is polynomial in the explicit graph description. On the promise family of lifts of `K_m`, this upper bound is `(m-1) ceil(log_2 r)` on `n=mr` vertices. It is not an upper bound for unrestricted graphs.
