# Workflow: full research cycle

Use the coordinator to split the task into scoped hypotheses. Spawn at most 4 independent exploration agents at first: lower_bounds, upper_bounds, algebraic_sketches, literature. Have experiments devise independent finite checks. Ask each to write a dated report under results/agents/<name>/, with exact statement and first difficulty. Select promising hypotheses and then spawn proof_auditor with only statement + baseline definitions, not proposing agent's proof. Once independent attempt is complete, expose the proof and solicit a line-by-line review. Repeat for each substantive result. Merge proven/conditional/refuted conclusions into results/CONSOLIDATED.md; update claim ledger; ask manuscript_editor to draft only vetted results. Never merge contradictory or unsupported claims.
